**What landed** (`acquire/match.py`, `acquire/match_cli.py`,
`acquire/fallback.py`, `intake/candidates.py`, `intake/acrcloud.py`,
`intake/cli.py`, `modules/outbound/tidal_account.py`):

- `bare_title` is a title's own text when it folds to nothing: NFKC, with
  spacing, the variation selectors and the invisible format characters taken
  out, the flag tag characters kept. For every other title it is empty. No
  casefold: over every code point that folds to nothing, case changes only
  two Greek combining marks, which compare equal either way, so it was dead
  code (the table's first measure found it a zero and it was removed).
- `title_identity` is the fold, or, for such a title, the bare text behind a
  unit separator `fold` never leaves.
- `same_title` is that identity's equality.
- `recording_identity` (`Wanted.distinct`, `Owned.distinct`) is the token
  with the title read that way. It equals the token for every title that
  folds to something.

Every comparison and identifier listed above reads the identity. The index
keys and the approximate pass keep the token, so discovery is unchanged.
