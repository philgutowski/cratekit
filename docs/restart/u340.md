**U340, #989, a track can sit in a second genre folder of BY GENRE + ENERGY
beside the one its genre names, built in the cloud lane on 2026-11-23.** A
track that belongs in two genres is filed into both folders, in the band its
one energy reading names in each, and every path that files or checks the
tree keeps it there.

**Who built it.** Planned and built by a thread on Opus 5.5 at high effort, a
large card: about 1,170 lines of source over two new modules and seventeen
changed ones, with a new verb that writes files. Round one was **Review: Opus 5.5 at
high effort, Fable out of usage**; round two was the `fable-reviewer` agent,
Fable at high effort, once Fable was back.

**The decision.** Where the second genre is stored was Phillip's to make; the
options went on the card with the recommendation first, and by his standing
instruction of 2026-11-21 the build took the recommendation without waiting:
a file tag of its own, `SecondGenre` (ID3 `TXXX:SecondGenre`, Vorbis
`secondgenre`, MP4 `----:com.apple.iTunes:SecondGenre`), never a second value
of the genre tag, which rekordbox would join into one word. rekordbox does not
show it, and nothing writes it to the database.

**What landed.**

- `routing.files_by_genre` and `routing.second_bucket`, the one rule: a second
  genre names a folder only beside a genre that names one, never through the
  fallback, never a word too coarse, never the first genre's own folder.
- `rebuild.filed_genres`: the derivation files the band, the genre sub and
  `with vox` in both folders, so `rebuild`, `converge`, `route resort`, mirror
  edits' wanted set and route's inbox and export all keep a track in both.
  `read_truth` reads the second genre in the same open as the energy.
- Adoption: the census reads the second genre of a routed track, and the plan
  gives such a track a second entry (`second=True`) with its own band,
  competing place and vocal place. Per track counts count `firsts()`.
  `adopt move` asks each entry about its own folder only (`claimed_buckets`,
  `elsewhere_of`), and its worker checks a move against the entry that planned
  it (`entry_for`).
- A split pair (Soul with R&B, either order) keeps both folders:
  `plan.kept_beside` drops a split place whose holder the track's other entry
  claims, asked by adoption's `competing_place` and by `move.held_in`, the one
  body the move plan, the worker's check and its read back share.
- Mirror edits: a band move inside either folder changes the energy and moves
  both; a move out of one folder into a third replaces that folder's genre
  only; an edit that does not say which genre changed, or whose genres would
  then file the track somewhere the account does not show it (a move into
  Electronica / Other, or one that wakes a second genre naming the genre's own
  folder), is listed and not taken, naming `crate tag second`. An unfile clears
  the second genre too.
- `crate tag second GENRE|--clear (--row|--rows-file|--playlist) [--leave]`,
  behind the explicit gate `tag.second.confirm`: writes the file tag only and
  reads it back, refuses a word that files nowhere, matches a playlist by its
  whole path (a folder name may hold " / "), and names the filing step that
  follows. Six `tag-second-*` causes, pinned.
