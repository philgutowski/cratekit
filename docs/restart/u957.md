**U957, #1025, the privacy scan lets a machine name that is an ordinary word
appear in prose and still catches it in paths and host names, built in the
cloud lane on 2026-11-23 and 2026-11-24.** A small card: a read only battery
script, nothing written or deleted. Filed from the attended session that went
to cut v0.19.0 after U339: the Mac had been renamed to a common English word,
`machine_identity_tokens` added the short hostname to the identity set, and
`portability_violations` matched it bare in ten tracked files that use the

**What landed.**

- **`scripts/scan_repo.py`, two reaches.** `machine_identity_tokens` returns
  `IdentityTokens`, a frozenset of every token as before that also carries
  `shape_only`: the detected tokens (login, home directory name, short
  hostname, mounted volume) that are ordinary words and not declared, in any
  case. `portability_violations` matches a `shape_only` token only where it
  names the machine: a home or mount path segment that is not a stand in
  (`/Users/<t>`, `/Volumes/<t>`, collected inside the existing path loops),
  or a host form from `_host_forms`: `<t>.local`, `.lan`, `.localdomain`,
  `.home.arpa` (not a method call), `user@<t>`, `scheme://<t>` or `//<t>`
  after a space, quote or bracket (not a `file:///` path or a path double
  slash), a UNC `\\<t>` (not an escaped drive path), and `<t>:/path` or
  `<t>:~` (not a URL scheme). Every other token, and every token of a plain
  set, matches bare as before, so a caller that loses the type over reports.
  The host pattern is compiled once per token and tried only where the token
  is written, under the same `re.IGNORECASE` rule.
- **What an ordinary word is.** `scripts/scan_ordinary_words.txt`, 39,579
  words: every entry of SCOWL size 35 (Debian's `wamerican-small`
  2020.12.07) that is four or more lower case ASCII letters, sorted, with
  SCOWL's permission notice in its header, read alike on macOS and Linux, a
  missing list raising rather than relaxing. `is_ordinary_word` takes the
  word whole in any case and refuses a mixed case token with an inner capital
  (`AirPort`). A declared token on the list is not looked for in the list
  itself (`ORDINARY_WORDS_PATH`); a name planted there is still caught.
- **Tests**, `tests/test_portability.py`'s U957 section, driving the real
  detection with `getpass.getuser`, `Path.home`, `socket.gethostname` and
  `MOUNT_ROOTS` patched: a detected word passes in prose; caught in every
  path and host form, written in cases other than the hostname's; not caught
  in the forms that are not a host; a stand in segment; the login and home
  tiers relaxed; an inner capital marks a name; a non word token still bare;
  a declared word bare from the file and the variable; identity off; the
  cloud exemption relaxes nothing; a plain set bare; the list well formed and
  pinned by digest; a declared listed word not looked for in the list; and
  the repository's files that write a common word, scanned clean with the
  hostname and a volume named by it, and red with it declared. Host literals
  are assembled from fragments and the parametrized tests take opaque ids,
  so a machine named by the fixture word does not fail the file or the
  mutation records.

**Decisions, recorded.**

- **A shipped list, not a shape rule.** The brief allowed either. A shape rule
  would relax every lower case handle (`jsmith`) to the path forms; the list
  relaxes only words. SCOWL size 35 was chosen over size 50 (63,072 words)
  as the smaller list that still holds all 36 words the brief's ten files
  share. Its licence is permissive and its notice ships in the file;
  `README.md` and `docs/vendoring.md` name it.
- **Which machine name it was, never written down.** The cloud proof does not
  name the Mac's word: it drove each of the 36 words the ten named files
  share as the hostname over every tracked file that writes it. At the merged
  head none is red except the two the code writes as a variable with a
  `local` attribute, which the base had red too (a residual); round one's
  reviewer inferred the word from the brief and found the whole tree clean
  under it in four cases.
- **The cost.** A shape only token is tried only where it is written, so it
  costs the scan less than a bare token did: over the tree's texts, 9.97 s
  against 11.08 s, 8.15 s with no identity, on this container.
