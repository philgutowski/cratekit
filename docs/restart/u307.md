**Decisions, recorded.** Questions of structure, none of them Phillip's:
- A module `__getattr__` forwards moved names (`native` to `native_plan`,
  `land_cli` to `land_native`), not a block of re-exports, which cost about
  forty code lines and was the largest single item between the first pass and
  the code target.
- `__all__` lists were removed where nothing star imports the module.
- `candidates.SEARCH_PAGES`, a module constant read from the label package at
  import, is served by a module `__getattr__` so `label` is imported at call
  time.
- Docstrings and comments shortened to the rule and its reason, by Phillip's
  answer of 2026-11-21 on #847; no docstring help is drawn from, no message,
  cause, gate wording or envelope key changed.
- One change of shape inside the write path, judged equal by the review: in
  `native.apply_rows`, a failure after the commit landed is recorded once,
  outside the handler, then raised; before, the record was written inside
  the handler. If writing that record itself fails, its error no longer
  carries the original as its implicit context. Driven base against branch
  by the round one review: the same exit, refusal and session record.
- The repository is not ruff formatted and nothing requires it, so no file was
  run through `ruff format`, which would also have moved the recorded
  mutations' text.
