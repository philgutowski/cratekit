**U176, #357, `crate acquire bandcamp` and `crate acquire bandcamp-fetch`,
built in the cloud lane on 2026-10-28.** The first verb lists every purchase
the account holds, newest first, each with its seller account and one
disposition (`new`, `owned` with the owned files named, `held` with the owned
tracks named, `not-downloadable`, `hidden`, `filtered`, `fetched`), and writes
nothing. The second plans the same way, queues one job item per `new` or
`held` purchase and drives it: each release downloads as FLAC, or another
lossless format, or a marked lossy one only where the policy allows it, every
file is checked against the policy and against the library again by its own
tags, and the rest move flat into `<download_staging>/<batch>` (default
`Bandcamp <date>`). Each purchase is recorded by id in `bandcamp_fetched.json`
in library state, so a later run plans only what is not fetched and a purchase
filtered out today is offered tomorrow. The session is
`crate login bandcamp-session --from-file PATH`; a missing, expired or refused
one is `auth-failed` naming that step.

Built against a client of Bandcamp's own endpoints (`acquire/bandcamp.py`)
rather than `bandcampsync`, whose state file is a checkpoint, whose missing
ignore file crashes it, and which logs part of the session. `curl_cffi` joined
the core dependencies for the browser fingerprint and is imported only by the
real transport; the suite binds a fake account through
`bandcamp_cli.transport` and an autouse guard refuses the real one.

**Reviewed on Opus, not Fable.** Fable's usage limit was reached before the
first round and still held at the second, so both rounds ran the
`fable-reviewer` agent on Opus. Round one found one blocking defect (a file
refused on a name collision was deleted while its purchase was recorded
fetched), two new suite failures (the doctor did not cover the credential, and
the download name was decoded by hand), and fourteen residuals, most fixed in
the same round. Round two confirmed each fix by driving it and found one
blocking defect the first round introduced (the doctor said no verb needs the
session); its fix, and the trust check moved onto the download page, closed the
round. Six residuals are filed in `docs/residuals/`.
