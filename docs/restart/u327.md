**What landed.**

- `crate analyze adopt` (`analysis/head_adopt.py` the engine,
  `analysis/head_adopt_cli.py` the verb), gated by the analysis module with no
  extras, since only that module stamps a head and the verb runs no detector,
  so it adds no dangling verb to the import rules. It follows `tag rows`'
  order: the backup acknowledgment, the plan on a read handle closed before
  the gate, the explicit digested gate `analyze.adopt.confirm` taking no
  inline answer (an empty plan still asks), `--leave CONTENT_ID`, then on
  apply the plan taken again on the write handle, refusing `decision-stale`
  if its digest moved.
- **The answer.** The key is the Key column's, read in either notation as
  padded Camelot, and wins on any difference, one step included; an unpadded
  head spelling the same key stands. The tempo is the BPM column's hundredths
  rounded half up, and wins when the head is more than one beat from it
  (`rekordbox_check.TEMPO_TOLERANCE`, the check's own rule). Only the key's
  span and the tempo's span of the leading head are spliced (`adopted`), so
  the body, the lossy marker and a body that itself begins like a head keep
  every byte. A missing key never stops the tempo, nor the reverse; each is a
  note on the item.
- **Three surfaces**: the row's `Title`, the file's title tag (planned off its
  own head, so a run stopped after the files continues by planning again) and
  `initialkey`, written only for a row whose title changes. **Left and named**:
  gone, not analysed, no head on the title, neither key nor tempo, an
  unmapped path or no path, a missing or unreadable file, a title tag whose
  body is not the row's, held out.
- **The write**, inside one guarded session: the policy asked of the whole
  plan before the first file; each surface's old value put in the record
  (`head_adopt_before`) before the capture is attached, which persists it;
  the files through `tags.write_tags` and read back; then `Title` alone for
  the rows whose files took, under the new operation `adopt-rekordbox-head`
  (`write/metadata.py`, `Title` owned), committed behind the guard, recorded
  from one `finally`, and read back so no other column moved. A file that did
  not take keeps its row's old title and the run ends refused under the new
  cause `analyze-adopt-unwritten`, naming titles, after the rest landed.
- **The scope** is the check's, less its fall back: INBOX / Analyze, or
  `--pass` / `--session`; an empty or unread INBOX / Analyze is an empty
  scope, said on every path (`adopt-scope-unread`) and shown at the gate,
  never the back catalogue.
- **`analyze check`** no longer reads suspect on key agreement alone (the
  floor is still measured and reported). It reads each row's tempo and head
  tempo, counts `tempo_differs` and `differs` (a row whose own title head
  names another key or tempo), and names `crate analyze adopt` in its key
  agreement check, now `info` when a title differs.
