**U249, #678, a sync pass reads each library file's tags once, however many
playlists it resolves, built in the cloud lane on 2026-11-12.** Filed from the
speed survey of 2026-11-12. Built on the suite's fakes and disposable tagged
containers; no library, account or rekordbox was touched. Size large by
rigour: it writes nothing, but the index decides what a landing matches,
refuses and files.

**The seam.** `match._read_from_disk`, the one reader `index_paths` calls per
file, now remembers each file's `Owned` for the life of the process, and its
old body is `_read_fresh`, called on a miss. Every caller of `index_library`
and `index_paths` gains and none changed: `library_view` and the intake worker,
`intake missing`, the landing's batch index, label filing, set playlists and
account playlists. Every index is still a fresh walk, so a file that is gone
is absent, a new or renamed file is read, and a pass of P playlists still
makes P + 1 walks; what it no longer makes is P + 1 opens of each unchanged
file.

**The key and the rules** (the note above `match._REMEMBERED`). The path and
the name template, and a stamp of size, `st_mtime_ns`, `st_ctime_ns`, `st_ino`
and `st_dev`. The brief asked for the first four; the change time and the
inode pair were added because they cost no extra stat and catch what size and
time alone cannot (`rsync -a`, `cp -p` or `os.utime` putting the old time back
over new bytes, a rename swapping same size files); a field too many costs a
read, never a stale answer. A file whose modification time is under two
seconds older than the entry's moment, taken before the stat and the read, is
read again (a FAT volume's step). Only a whole read is remembered:
`tags.read_tags_noting`, new, gives `read_tags`'s lenient answer and whether
any part of it failed through one open, so a failed read is indexed as it
always was, remembered never, and forgets what an earlier whole read left. A
file that cannot be stat'ed is read as before. `match.reset_cache()` forgets,
`intake.cli.reset_cache()` calls it, and the autouse fixture
`_forget_library_reads` in `tests/conftest.py` clears it around every test.
Nothing is kept across processes.
