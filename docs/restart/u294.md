**U294, #851, `crate tag campaign` applies the needs genre backlog in one
campaign under one rehearsed gate, built in the cloud lane on 2026-11-21.**
The writing half of U292 (#849), split at that card's plan. U292's read only
`crate tag backlog` sorts every needs genre row by cause and names the
existing gated verbs that settle it, in order; driving them by hand is five
verbs and five gates. This verb is that campaign under one approval. Large.
Built on disposable databases, real tagged containers and recorded catalogue
answers; the live run is owed (below).

**The verb.** `crate tag campaign [--alias WORD=GENRE] [--folder WORD]
[--leave-word WORD] [--catalogue] [--rehearsed DIGEST]`
(`cli/verbs/tag_campaign.py`, a `tag.campaign` registry entry on the
repair module, destructive, writing files and database metadata, one
explicit gate `tag.campaign.approve` with `apply` and `abort`). A composer,
as `crate organize` is (U112): it owns the order, the one gate and the stop,
and writes nothing itself. In order:
- the backup acknowledgment is read before the plan (R-733);
- the backlog is planned by `tag backlog`'s own plan on a read handle;
- each answer is checked against the plan before anything is written: a word
  the backlog does not ask about, a settled word given another answer, an
  unanswerable word and a word answered twice each refuse, and a word the
  copy already holds as given is taken as given, so the same command runs
  again once it has landed;
- every word the third step writes is planned by `taxonomy alias`'s and
  `taxonomy folder`'s own edits, each on the text the words before it leave,
  and each alias with that verb's own walk of the files it retags;
- one gate over one digest: the backlog's, the answers' and every file an
  alias retags, by its path under the library root. It names no copy, so a
  rehearsal digests equal to the live plan, and `--rehearsed` sets the
  rehearsal's digest beside the live one. An empty plan still asks.

Then each step through its own verb's plan and apply, each planned on the
library the steps before it left (R-1732):
1. `tag rows`, narrowed to the rows the backlog served. A routed row it would
   move into needs genre, or any other routed row, is held out (R-1734).
2. `tag suggest` at the backlog's floor, `high`, narrowed to the proposals
   the gate showed with the genre it showed. One that appeared or moved since
   is left and named.
3. The words: each settled word's one answer, then each answered word, each
   planned again and refused as stale when its edit or its files moved.
4. `tag rows` again, narrowed to the rows of the words step three wrote and
   to a file carrying the answer's own spelling.
5. `route resort` is named, not run.

A step that refuses stops the campaign there: its own refusal, reworded to
name each step that landed with its count, the step that refused and the
steps not run. What landed stays landed, and a second run plans only what is
left. Needs genre is measured by the backlog's own census before the
campaign and after each step that landed (R-1737), never projected.
