**U157, #338, the dyn My Tag for tracks whose tempo moves, built in the cloud
lane on 2026-11-01.** `crate analyze run` now measures a drift beside the head:
the tempogram the head already takes is cut into ten second windows, each
window's peak is found within a quarter of the head tempo and interpolated as
R-744's is, a window with no pulse (too little onset strength, or no clear
autocorrelation peak) is passed over, and the drift is the spread from the
tenth to the ninetieth percentile of the windows' tempos as a percent of their
median. Fewer than three windows with a pulse is `unknown`. The finalize writes
it as two new file tags, `driftlevel` (the percent, one decimal) and `drift`
(`steady`, `variable` or `unknown`), and neither is a tempo. The cut is a
setting, `analysis.drift_cut`, 1.5 by default and refused at load unless it is
a percent above zero; `core.drift` holds the verdict words, the comparison and
the Analyze Tracks settings each kind of row takes.

Every native landing (`intake land` and `intake file`) reads each added row's
drift against the cut configured now and gives each variable row the `dyn` My
Tag, under an `Analysis` category found by name or made, in the same guarded
commit and through the vocals verb's writer, as U127 writes `vox`. The digest
covers the cut and every row's drift, verdict and answer. The gate screen's
`dyn My Tag` line counts the tagged rows and the unscored files; an added item
shows its drift, verdict and answer when its file carries a reading. A file
with too little pulse lands as steady, and a file analysed before this unit is
unscored, counted on the screen and never tagged. The `rows-await-analysis`
warning names both selections with their counts, Normal (high precision off,
BPM/Grid, Phrase and KEY on) for the rows without `dyn` and Dynamic for the
rows with it, and the sync stop's printed step says the same. A variable row
the commit could not mark, because the library has no My Tag category to copy
or the value was one rekordbox removed, is named under the new warning
`dyn-not-written`. The reader of the mark, `dyn_marked`, moved beside its
writer in `intake/native.py`, and `crate analyze check` imports it and the
`dyn` value, so the two read one answer.
