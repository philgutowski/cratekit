**U193 built, 2026-11-02, in the cloud lane on
`cloud/464-a-guard-that-stops-any-one-comma`, issue #464: a call ceiling stops
any one command before it spends a massive number of provider calls.** Filed
from Phillip's note on the decisions page that there should be a general guard
against massive provider calls, and built on his three answers: a line per
command, a stop that keeps what it did and prints how to continue, and 500
calls by default, configurable.

The provider gate is the seam. The dispatcher opens a command scope in
`core/provider_gate.py` around every verb, recording this process's call count
at the start, and `Gate.call` asks under its lock, before the send, whether the
command has already made `[provider] calls_per_command` calls, 500 by default.
If it has, the call is not made and the refusal, `provider-call-ceiling`, is
the job engine's park, the breaker's own path: an item in flight goes back to
pending, what the run did is kept, and the count at the stop is the ceiling
exactly. A nested dispatch (`run decide --continue`) keeps the outer count.
Outside a scope nothing is capped, which only a library caller or a test is.

`--calls N`, a new global option, raises the ceiling for one run, and reaches a
job's detached child through `CRATEKIT_PROVIDER_CALLS`, written only while the
scope is open and restored after, so the next run reads the configuration. A
hand written value that is not a positive whole number is ignored, leaving the
configured ceiling, the lower one. The configuration refuses a ceiling that is
not a positive whole number at load. The refusal names the exact command that
continues, with the ceiling doubled: `crate --calls N job resume JOB_ID` when
the command was driving a job, which the engine now names on every parked
cause it records (a cause that names its own job keeps it), otherwise the same
command line with its global options and `--calls N`. The cause the job stores,
which `job show` reads when a detached child stopped, names both forms. A verb
that catches the park and answers normally carries a `provider-call-ceiling`
warning saying what was not read. The label playlists crawl gate also asks
when its estimate is over the ceiling, counting what the listing spent, with
the figure that reads it in one run, and its reason names the ceiling when only
the ceiling asks.
