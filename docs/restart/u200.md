**U200, #486, the cloud battery and the mutation driver read every test with

**The change.** `cloud_battery.py` gains `ensure_full_history`, which reads
`git rev-parse --is-shallow-repository`; on `true` it runs `git fetch
--unshallow origin main` and reads it again, and on any answer but `false`
after that, an unreadable one included, it refuses with the reason. `baseline`
and `compare` call it before ruff, the scan or the suite, and stop with exit 1
when it refuses, so a refused baseline writes nothing. The baseline's header
now ends `history full`. `compare` refuses a baseline whose header lacks the
field, one written before this card or by hand, and says to measure it again.
`mutate.py` reads the same field: `read_known_failures` refuses a file whose
first line is not a `# commit` header ending `history full`, and `main`
refuses known failures on a clone that is shallow or whose shallowness git
cannot report. The driver only reads git and never fetches, as the brief
asks. The cloud unit skill (steps 3 and 7), METHOD's cloud lane paragraph and
the shallow clone `docs/solutions/` entry say so in a line each.

**Measured on the tree.** The base 1631ed99, after `git fetch --unshallow
origin main` on this container, fails 163 ids, the count R-1191 measured with
