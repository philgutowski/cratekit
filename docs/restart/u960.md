**U960, #1079, `crate status` carries one machine readable glance an app can
show, built in the cloud lane on 2026-11-25.** A medium card (read only, no
path that writes or deletes), the first engine card of the menu bar app
(idea #377), built beside #1080, #1082 and #1084.

**Who built it.** Planned and built by a thread on Opus 5.5 at high effort.
Review: Opus 5.5 at high effort, Fable out of usage, as a general purpose
agent given the `fable-reviewer` definition, two rounds, the cap.

**What landed.**

- **The glance** (`cli/status_glance.py`, new): `crate --output json status`
  carries `data.summary.glance` with `version`, `attention`, `backup`,
  `rekordbox`, `jobs_running`, `gates` and `night`, each read through the
  reader the verb that owns it uses, no probe of its own:
  - `backup`: `backup_facts.ages`, doctor's `backup.age.*` reader, per portion
    `{state, age_seconds, completed_at}`, keyed off `Portion`. Read only when
    `core.preflight.library_state_is_readable` holds for the mount, since the
    record is on the library volume (review round one).
  - `rekordbox`: `processes.rekordbox_processes_running`, doctor's
    `rekordbox.closed` probe. `AbsenceUnconfirmed` is `unknown`; any other
    raise is unreadable.
  - `jobs_running`: jobs in state `running`, `{job_id, verb, state}`, the verb
    being the handler key, off `jobs.read_jobs`.
  - `gates`: every run record with an open gate, `{run_id, verb, gate,
    options, explicit, writes_database, since, old}`, `writes_database` from
    `gates.writes_the_database`, `old` from `gates.old_gate(...).retirable`
    at `reports.open_gate_stale_days`, `since` from `gates.idle_since`. Listed
    with `os.listdir`, never a glob; a record that cannot be read is an item
    `{run_id, unreadable}`, an unlistable directory makes the key unreadable.
  - `night`: `sync_night.settle(sync_night.read_status())`, as `--last` reads
    it, projected to `outcome, line, gate_run, pass_run, staging`, or null.
  - `attention`: `fail` (any source or item unreadable, or a backup recorded
    ahead of now), `gate`, `running`, `backup-due` (a portion at
    `session_ack.SESSION_MAX_BACKUP_AGE`, five days, or with no age), `ok`.
- **The read only queue reader** (`core/jobs.py` `read_jobs`): `mode=ro`, no
  directory, mode or schema; an absent queue is no job, any other failure
  raises. `list_jobs` shares its query.
- **The verb** (`cli/doctor.py` `status`): one call, imported where it runs so
  `crate doctor`'s help stays under its import ceiling.
- **The human line** (`cli/render.py` `render_attention`): `attention: <word>`
  after the verb's line, gated on the payload, naming each key that could not
  be read (review round one).
- **The schema** (`tests/schemas/status_glance.v1.json`) and 53 tests in
  `tests/test_status_glance.py`, among them the agreement test driving
  `crate doctor`, `crate status` and `crate sync night --last` over one
  fixture, the old flag against `run retire`'s own list, and a byte check that
  the glance writes nothing.

**Timing.** `crate --output json status` as a fresh process on a synthetic
installation with 3,000 jobs (30 running) and 200 run records (100 at a
gate), three runs each, on this container: 0.40, 0.69 and 0.53 seconds at
`c9b0c233`; 0.50, 0.68 and 0.58 at the final code, the mount probe added. The
glance alone 0.017 to 0.042 seconds. With 2,000 run records: 0.63 to 0.84 for
the verb, 0.10 to 0.13 for the glance. Under the brief's two seconds. Review
round one measured 20,000 run records at 1.39 to 1.54 seconds for the verb
(residual c). Not measured on a Mac.

**Decisions the session made.** A backup completion recorded ahead of now
reads `fail`, as doctor fails it, never `backup-due`. A scan that could not
confirm absence is `unknown` and raises no word, as doctor says it as a note.
`jobs_running` lists `running` only, the brief's letter. A gate this build no
longer declares shows `options` empty and `explicit` null, unknown rather
than guessed. The glance carries a `version`, so the app can refuse a shape
it was not built for. Night fields are text, as `--last` prints them. The
glance's key for the application is one named constant, since the process
guard forbids the name inside a container.

**Hard constraints, held.** No beat grid, tempo or BPM anywhere; the glance
writes nothing, the dispatcher's run record for the verb aside, as for every
verb. SQLite may leave the queue's two sidecar files when it opens the store
read only; the queue's bytes are unchanged, tested. No rekordbox launch, no
network call.
