**What landed.**

- **`pair_cli.py` split** along what the verb does in turn: `pair_model`
  (constants, targets, scopes and the clock), `pair_read` (the landing and
  job reads), `pair_plan` (`plan_pair` and its helpers), `pair_screen` (the
  plan shown, the gates' facts and payload, the warnings), `pair_write` (the
  steps and the two writes), `pair_check` (the held plan and the check before
  the write), and `pair_cli` (the verb's builder and handler). Every name
  another package or a test outside the card reads stays importable at
  `cratekit.sync.pair_cli`, and the names the suites patch (`_now`,
  `AGREE_AFTER`, `file_identity`) are read through the module that holds
  them, so one patch still reaches every caller.
- **Seams**: every top level import of `label`, `favorites` and the outbound
  module moved into the function that needs it or behind `TYPE_CHECKING`, so
  `sync all`'s builder imports no toggleable package. `sync/playlists.py`
  answers `AccountPlaylist`, which organize's suite reads there, through a
  module `__getattr__` that imports it on first use (round one's finding).
- **Duplication**: the blocks `mark_cli`, `strip_cli` and `unmark_cli` shared
  have one home, and sync's allowance file is empty.
- **Prose**: docstrings and comments in all 32 source files and the 27 test
  files cut to the rule and its reason (Phillip's answer A on #847), each
  file's syntax tree with docstrings removed proved equal to the base. Help
  text, gate wording and refusal messages are untouched.
- **Scenarios**: four files under `tests/behaviour/` (`sync_pair`,
  `sync_pair_every`, `sync_twins`, `sync_marks`) run 27 of the sync suites'
  own tests through the stage, one or two a state: fresh, merged, reordered,
  settled, stopped and continued, held, tied, adopted, resumed, unread,
  window lag, brought back, twins and release, mark, unmark, strip and the
  taken ledger, and the refusals.
