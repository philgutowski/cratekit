**The guards, in the order they run.** Without `--send-to-cyanite` the run is
a plan: the count to upload, the files not sent and why, and with
`--price-per-track` the estimated cost, said before anything else, and
nothing sent, no key read. With it, `--cap` and a finite `--price-per-track`
are required and a count over the cap refuses; an output or summary already
there is never overwritten without `--resume`; the key is read from the
keychain (`cyanite-key`, `crate login cyanite-key --from-file PATH`), no key a
`CredentialMissing` naming that step; a free preflight query proves the key
(a 401 or an unauthenticated GraphQL error is a `CredentialRejected`, never
sent again) and the read query's shape before any upload. The key goes only in
the `Authorization: Bearer` header of the requests to
`https://api.cyanite.ai/graphql`, never to the presigned upload address,
which must be https and is never written, out of every `repr`, and every cell
and message is scrubbed of it; a transport failure is said by its type only.
No query names anything tempo or key shaped, the wire is checked, and a
reply's other fields, its tempo and key among them, are dropped unread. The
trial writes its table and summary and nothing else: no tag, no record, no
library, the configuration read with `write_back=False`.

**What stops a run and what is one file's.** A rejected key, a refused query,
a 403 or 429, an outage, Cyanite's full library, or an analysis never started
(the account's analysis limit) stops the run before another upload, rows kept,
exit 1. An upload refused, a create refused or an analysis failed is that
file's row. A file is known by the SHA-256 of its audio past its ID3 tags, so
a moved folder or a retagged file is not paid for again, and two files of the
same audio are sent once. A file's row is written, pending, the moment
Cyanite answers the create, ahead of the five minute analysis wait, so a run
ended mid wait by anything, a signal included, keeps the track, and a
`--resume` asks about it without uploading. The summary is written in a
finally. Exit 0 done or the plan, 1 stopped partway, 2 refused with no audio
uploaded.
