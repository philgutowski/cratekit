**U178 built, 2026-10-31, in the cloud lane on
`cloud/358-a-registered-label-can-carry-its`, issue #358: a registered label
can carry its genre, so `crate tag folder` tags every file of the label with
it and asks no catalogue.**

The registry gains `genre` per label, set with `crate label registry add` or
`set` and `--genre WORD`, kept as typed and cleared with `--genre default`. It
is checked by routing, `routing.resolve_bucket`, when it is set: a word reaching
a bucket by an alias, a bucket's own name or a keyword rule is stored and the
screen says which bucket and how (`Rominimal` reaches Minimal / Deep Tech by
the keyword `minimal`); a word reaching only the fallback is refused under
`label-name-invalid` unless `--accept-fallback`.

`tag folder` freezes every registered label genre into the job when it queues
it (KTD9) and takes `--label NAME` for the files that carry no label tag; a
`--label` nobody registered is refused `label-unknown`, one with no genre
warns `tag-folder-label-no-genre`, and an unreadable registry refuses only a
sweep given `--label` and warns `tag-folder-label-registry-unread` otherwise.
The engine reads a file's label tag through the new `label` entry of
`core/tags.FIELDS` (Vorbis `label`, ID3 `TPUB`, MP4 freeform `LABEL`, Picard's
keys; U177 measures rekordbox's Label column), and the file's own tag outranks
`--label`. A file with no genre whose label has one is given it before any
search, source `label-genre`, its record naming the label; a file with a
picture asks nothing, one without is searched for its art only and a refusal
there is an `unavailable` picture. A file that already has a genre keeps it,
stated in `CONCEPTS.md` under **Label genre**. The summary counts
`tagged_by["label-genre"]`, `label_genres` per label, and `label_tags`, the
files whose own tag kept them from `--label`, with the warning
`tag-folder-label-tag-outranked`; a `--label` typed on a resume warns
`tag-folder-label-on-resume`. `docs/GUIDE.md` has the two commands.
