**U167, #348, `crate analyze check`, built in the cloud lane on 2026-10-31.**
A new read only verb answers, after the rekordbox visit, whether every landed
row is analysed, whether each grid is right, whether the Key column is
filled, and how far rekordbox's key agrees with the title's. The engine is
`analysis/rekordbox_check.py` and the verb `analysis/check_cli.py`, core
rather than the analysis module's, since it runs no detector and needs no
extra. It reads a disposable copy of the database through `read_only_copy`
and each row's `ANLZ0000.DAT` as bytes, walking the tags by their headers and
parsing only the beat grid tag with pyrekordbox's own structure; it never
holds the serialiser the grid guard forbids, and a test watches every open
and every byte under the library. What analysed means is
`intake.analyzed.member`, the clear's own reading, made public for this.

**Scope and verdict.** `--pass NAME` or `--session ID` names a landing and
wins; otherwise INBOX / Analyze when it holds rows; otherwise every live row
rekordbox has not analysed. A named landing nothing recorded, one whose
playlists hold no live row, or one whose every row left the collection
refuses (`analysis-check-landing-unknown`, 30), never reading as an empty,
clean scope. The verdict is the exit status: done 0; waiting 12, a pending
action this verb verifies; suspect 27 under `analysis-suspect`, for a
variable grid on a row not marked `dyn`, an analysed row's grid missing,
absent or unreadable, or title keys equal to rekordbox's below the recorded
rate by more than three standard errors. Suspect outranks waiting. An empty
scope ends `no_op` and says nothing was checked. One step on the Camelot
wheel is a neighbouring number with the same letter, or the relative major or
minor. The `dyn` mark is any live My Tag value named `dyn`
(`rekordbox_check.DYN_VALUE`), which U157 should write and import.

**Decided against the brief.** The brief said the check works with rekordbox
open. It does not: `read_only_copy` refuses while rekordbox or its agent
runs, because a copy taken under the live application is torn, and CLAUDE.md
wants both gone before any verb runs. The brief was amended to say so. A
named landing outranks the playlist, against the brief's order, because a
flag the person typed should not be ignored.
