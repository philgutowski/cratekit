identifier are never kept. It is written every 50 new answers and in a
`finally` on the way out of the roster, so a ceiling or breaker park keeps
what the run read; a refused write is said, never raised; a document that
cannot be read refuses `label-listing-kept-unusable`, exit 30, before any
call, naming the file to delete.
