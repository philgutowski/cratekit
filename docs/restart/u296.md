**The duplication check.** `tests/test_duplication.py`, 23 tests. A logical
line and a block are the brief's. **The allowance is held in windows of
exactly six logical lines, one line per place, the session's call**: the
baseline's 143 blocks are maximal runs, and a maximal run's digest changes
when another package removes a partner copy, which would fail a package whose
own lines did not change. A window either still stands twice or it does not,
so removing a place of a copy can only shrink what is found, and
`test_removing_a_partner_copy_does_not_fail_the_package_that_kept_its_lines`
drives the case whole blocks would fail. 436 window places in 19 files under
`tests/ratchets/duplication/` pin the 143 blocks. A third copy of an allowed
window in the same package fails, because the allowance counts places, and an
allowance excuses no other package. The limit, found by the review and now
said everywhere the claim is made: an edit that brings two stretches of lines
together forms a window that was never there, which fails as the new copy it
is.
