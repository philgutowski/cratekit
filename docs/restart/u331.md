**The decision the brief asked for, made in the rule.** A listed module
answers for the names it defines and for the names it re-exports from
another module, each counted against the names ceiling; it never hands a
feature package a whole module. The measure follows a module reached as an
attribute of, or imported from, a listed module (`tags.art.read`, `from
cratekit.core.tags import art`) to the module itself, keeping the use as
written beside it, so that spelling is a reach off the list and not one
counted name. Fixture tests pin both readings. Only top level imports hand
a module over (a function local import does not), through as many modules
as pass it on.
