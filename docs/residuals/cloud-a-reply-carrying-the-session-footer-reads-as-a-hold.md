---
title: A reply on a card that carries the Claude Code footer is read as the cloud session's own comment, so it holds the lane rather than answering
found: at the Fable review of the cloud-first commits, 2026-10-27.
issue: no
---

**The mechanism.** `board.py cloud` tells the session's comments from
Phillip's only by the footer the harness appends, `Generated by [Claude
Code]`, because every comment on the card is posted by the same login. A
reply to a `Brainstorm` that carries the footer, from any other Claude
session posting for him, is read as the session's own comment under an
unknown heading, which is a hold. The lane is held for eight hours, then the
card is offered as `resume`, and the resuming session skips the brainstorm
fold.

**Measured cost.** Driven at `cloud_state`: a `Brainstorm` then a footer
comment reading "Go with A" gives `underway`. The producer was surveyed, not
driven: of the last hundred comments on the repository three carry the
footer, all from the cloud session on #319, and none of Phillip's.

**Closes when:** the session marks its own comments with a token no other
session writes, such as a hidden marker naming the lane, and the reader keys
on that instead of the harness footer. Ledger only: nothing a person does
today produces it.
