Two batches, 24 rows, 23 killed. The author's own, so every count below is what

## The shape of the unit, and why the rows are grouped the way they are

One fact travels from the tier that knows it to the person who ran the verb.
`routing.suggest_tag`'s last tier sets `off_taxonomy`, `searchers._resolved`
carries it onto the hit, `tag.tag_one` takes it on the one branch that wrote a
word, `tagging.cli.handle` puts it on the committed artifact, and `_summary`
counts the distinct strings and warns. Group A mutates the tier, B the carry, C
the report and its warning, D a fixed sample of this unit's existing guards.

## The rows worth reading twice

**`A1`, 6 deaths.** Reverting the flag entirely is the state before this unit:
the last tier answers and says nothing about having answered. Six tests notice,
across the resolver, the searcher and the sweep's report, which is the chain
working rather than one assertion repeated.

**`A3` and `A4`, 1 death each.** These two are the built in review's findings
held in place. `A3` widens the suppression from the routing tier to the declared
VOCABULARY, which is what the first build did and what hides a sub's display.
`A4` makes the suppression case insensitive, which hides a lowercased Bandcamp
tag. Each kills, so neither mistake can come back quietly. They are worth one
death rather than six because only one test drives each, which is the honest
size of the cover.

**`A2`, 2 deaths, against `A6`, 3.** The pair the flag exists for. `A2` flags a
bucket's own display, `A6` flags a declared rule carrying a literal tag. Both
have no bucket, both are ordinary answers, and neither is a gap anybody needs
telling about.

**`C8`, 1 death.** The warning CODE is reworded rather than appended to, on
METHOD's rule, and it dies because the test pins the literal and not only the
constant's name. A log filter matches the literal.

**`D2`, 2 deaths.** An existing guard, sampled unchanged: an answer too coarse
to be a final tag is a decline and not a hit. It still bites, which is what a
sample of existing guards is for.

## The one zero, and what holds the property instead

`C2_summary_counts_skips_too` killed 0, promoted to the full suite, 9884
collected against a 9884 baseline. It moves the off taxonomy count out from
under the branch that wrote a word, so a SKIPPED file's report could enter the
map.

It is a PLACEMENT and not a check, and nothing dies because no committed
artifact can carry that pair. The engine is what makes it impossible:
`tag_one` reads the flag off the hit only on the write branch, so a
`has-genre` skip, which IS searched and so DOES hold a hit, never records it.

`r650-b` pins that rather than arguing it. The composite
`C2_composite_the_engine_holds_it` mutates exactly the engine line that holds
the property and kills 1. So the honest reading is: **the placement in the
report is defence in depth over a shape the engine prevents, and the engine is
what is tested.** That is the same belt and braces this repository already uses
where `retag.options_for` filters catch-alls at the offer and the write refuses
them again, and the note is here so a later reader does not mistake the zero for
an untested report path.
