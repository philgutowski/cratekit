# Reading r361-a

One batch, 15 rows, 15 killed. The author's own, so every count is what the
person who wrote the code could kill and not what an independent table would
find. METHOD records that gap with numbers: independent tables have found 17
where the author found 10, 49 against 39, 83 against 49.

## The shape of the unit, and why the rows are grouped the way they are

One name rule, asked on two paths. `exclusion` asks it to decide what a pass
OFFERS, and `pending_marks` with the mark verb's `_decided` ask it to decide
what is RENAMED. The second path is the built in review's finding: the first
build asked it on the offering path only, and a debris job that reached the
cursor anyway, the fourth sitting's eleven once resumed or one queued by hand,
would have had the source system's throwaway renamed under it. Group A mutates
the rule and both paths, group D is a fixed sample of the exclusion's existing
guards.

## The rows worth reading twice

**`A1`, 3 deaths.** The brief's required row, the suffix check dropped from
`exclusion`. Three tests notice, the seam test, the verb test over the sitting's
names and the check's tally, which is the chain and not one assertion repeated.

**`A3` and `A4`, 1 death each.** The leading space dropped, and `endswith`
widened to `in`. Each dies on exactly the assertion written for it,
`ColorizeLIBRARY` and `LIBRARY Colorize`, which is the honest size of the cover:
one test pins the suffix's shape, and the row says it is pinned.

**`A2`, 3 deaths.** Case folded, so `Colorize Library` is debris. The unit test,
the verb test and the mark set test all list that name and all expect it kept,
because it is a name a person could give and the batch never writes.

**`A5`, 2 deaths.** The order flipped, debris before the prefix. A prefixed
debris name is told `label-debris` instead of `already-swept`, and both the seam
test and the mark set test pin the prefix as the first reason.

**`A6` and `A7`, 2 and 1.** The renaming path. `A6` lets `pending_marks` offer a
recorded debris playlist to the mark, `A7` lets the verb's plan fall through to
the reports for it. Each is the review's finding held in place, and each dies on
the test written after the finding.

**`A8` and `A10`, 1 and 4.** The word respelled, in the verb and in the enum.
`A8` dies once because only the verb test reads the reason off the plan. `A10`
dies four times because the enum's value is what every report carries, and it
is the row that says reading the word through the enum was the right call: one
spelling, pinned in four places.

**`A11`, 2 deaths.** An empty count asked before the suffix. It is a maintainer
facing row about the order after the prefix, and it dies because the seam test
gives a debris playlist a zero count on purpose and expects `label-debris`.

**`D1` and `D3`, 4 each.** Existing guards, sampled unchanged: the swept prefix
and the open job. Both still bite hardest of anything in the table, which is
what a sample of existing guards is for.
