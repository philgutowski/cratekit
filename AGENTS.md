# Agent instructions

This repository is the Cratekit source. What to read depends on which of two
jobs you are here for, and they are not the same job.

**Building Cratekit.** `CLAUDE.md` next to this file is the session contract,
and it names what to read next. Any coding agent should follow it, whatever tool
it runs under. It is named for one tool and none of it is specific to one.

**Running Cratekit against a real library.** Do not work from this checkout. The
operator workspace is the `operator/` directory, meant to be copied outside this
repository, and the README's "Working with an AI assistant" section has the
steps. This checkout's instructions are about building the product and will
point you at the wrong things: the board, the test battery, and a merge
discipline that has nothing to do with running a library workflow.
